# v0.18.0: Pushes deliver again, exercise names in your language, and a coach's assistant on /me

Previous tag: v0.17.0 (heart_models 2.57.1 → 2.61.0; heart_aws and heart_design unchanged).

## Compatibility

Every contract change since v0.17.0. Coaching still has no installed reader: up to Android 1.17.3
and iOS 1.17.1, the app calls none of `/connections`, `/threads`, `/keys` or `/coach/clients`, so the
coaching rows below reach no installed caller.

| Change | Kind |
|---|---|
| `GET /programs/history?since=`: each of the caller's programs whose history changed since the cursor, with all its steps and bases, up to 50 programs a page | additive |
| An answer that names an exercise inside a workout, a template, an anomaly or a coach's view of a program names a library exercise in the request's `Accept-Language`, with the exercise list's fallback; an own exercise keeps its owner's name. Installed builds read these names as display text | additive |
| `PUT /exercises/:exerciseId`: `instructions` set to `null` or blank text clears them, and an edit without the key keeps them. Blank text was a `400`, and `null` kept the text. Installed builds leave the key out when there are no instructions (`'instructions': ?exercise.instructions`), so they never send `null` | widening |
| `POST /exercises`: blank `instructions` read as none | widening |
| `PUT /exercises/:exerciseId` with an id that can't be a UUID is a `404` rather than a `500` | fix |
| `POST /accounts/tokens` takes an optional `scopes`: `read`, and `read:coaching` beside it. Anything else is `400 token_scope`. Without the field a token is `read` alone, as before | additive |
| `PUT` and `DELETE /connections/:connectionId/name`: a coach's own name for a client. `namedByYou` on connections, the roster and the feed, `otherNamedByYou` on threads, `studentNamedByYou` on program holders | coaching, no installed caller |
| `GET /accounts/:userId/programs/:programId`, the coach's view of a client's copy, adds its steps, bases and marks | coaching, no installed reader |
| `POST /accounts/:userId/programs/:programId/bases` is gone: the client's device moves its own bases | coaching, no installed caller |
| Pushes name the sender by their own name, never by a name a coach gave them | coaching pushes, no installed receiver |
| `/me/coaching/...`: ten `GET` routes for a coach's clients, needing `read:coaching`; a token without it is `403 insufficient_scope` | additive (developers, below) |
| `heart_models` 2.58.0 to 2.61.0: the naming and the coach's view above (2.58.0, 2.59.0), `ProgramHistoryChanges` for `GET /programs/history` (2.60.0), `ServerRefusal` for a refused request (2.61.0) | additive |
| 5 migrations: `profiles.created_at` NOT NULL, exercise names per locale, given names, program histories, the push token as its table's key | database; what reaches a response is in the rows above |

Oldest app served correctly: **1.12**, as before. `MIN_APP_VERSION` stays **1.13.0**, not

## Developers

Detail on the token surface: https://heart-of.me/developers.html.

- **`/me`:** someone who coaches can read their clients who share their training with the
  assistant: `GET /me/coaching/clients`, `/me/coaching/feed`, a client's `workouts` (and one
  workout), `programs` (one, and its `changes`) and `goals` under
  `/me/coaching/clients/:clientId/`, and their own library at `/me/coaching/library` (and one
  program). Each needs a token with `read:coaching`. One without it is refused with
  `403 insufficient_scope` and a `WWW-Authenticate` challenge naming the scopes to ask for.
- **`/me`:** an OAuth grant offers `read:coaching` when asked for, always beside `read`. One that
  asks for no scope still gets `read` alone.
- **Personal tokens** can be made with `read:coaching` beside `read`.
- **`/me`:** records and history name library exercises in the request's `Accept-Language`.
- **MCP:** a personal token made with `read:coaching` is offered the coach's tools. One made without
  it is told to connect by signing in. The tools keep English names.
- **MCP:** a coach's tools name each client as the coach named them.
