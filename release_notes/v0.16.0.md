# v0.16.0: Coaching, behind the beta

Previous tag: v0.15.0 (heart_models 2.39.0 → 2.51.0; heart_aws 1.1.0 and heart_design 1.0.0,
unchanged).

## Compatibility

Every contract change since v0.15.0. Coaching is the bulk of it. No installed build (1.13 or since)
calls `/connections`, `/comments`, a coach's reads of `/accounts/:targetUserId/…`, or receives a push,
so the tightenings below reach no installed caller.

| Change | Kind |
|---|---|
| 63 new routes: `/invitations`, `/invitation-links/:token/…`, `/blocks`, `/push/settings`, `/keys/…`, `/connections/:connectionId/thread`, `/threads/…`, `/notes`, `/reports`, `/library-programs/…`, `/coach/clients`, `/coach/feed`, `/programs/:programId/start`, `/programs/:programId/changes`, `/workouts/:workoutId/plan`, `/workouts/:workoutId/hidden`, `/workouts/hidden`, and a coach's `/accounts/:targetUserId/programs/…`, `/accounts/:targetUserId/workouts` (POST), `/accounts/:targetUserId/skips`, `/accounts/:targetUserId/workouts/:workoutId/plan`. Each, with its error codes, is in `docs/2026-11-07.coaching-api.md` | additive |
| `GET /connections` and the other connection answers add `connectionId`, `acceptedAt` and `shares`; `PUT /connections/:connectionId/shares` is new | additive |
| Workouts add `loggedBy` and `loggedByName`; programs add `coachId`, `coachName`, `waitingSince`, `revision` and `sessionRevisions`; the profile adds `entitlements` | additive |
| `POST /devices` takes an optional `utcOffsetMinutes` | additive |
| `PUT /programs/:programId` and `PUT /templates/:templateId` on a coach's copy take an optional `baseRevision` and `changeId`, and answer `409 program_changed` only when a `baseRevision` is sent. A write without one is accepted and recorded as `stale`, so a build that doesn't know copies writes as before. `DELETE /templates/:templateId` on a copy answers as before and is recorded in the copy's history | additive |
| `POST /connections` refuses `COACH` and `STUDENT` (`400 invitation_required`): a coaching connection starts from an invitation | tightening, no installed caller |
| A pair holds one connection per domain across both directions; `DELETE /connections/:connectionId` keeps the row as `severed`, and a severed or declined coaching row no longer goes back to `pending` | tightening, no installed caller |
| Only the student resumes a paused coaching connection (`403` for the coach on `PUT /connections/:connectionId`) | tightening, no installed caller |
| A coach's reads of `/accounts/:targetUserId/workouts`, `…/workouts/:workoutId` and `…/goals` narrow: workouts from acceptance on (or all, with `history` shared), never hidden ones or ones started while paused, no images; goals only with `goals` shared. A hidden or out-of-scope workout is a `404` | tightening, no installed caller |
| Comments follow reads: commenting on, or reading comments of, something the caller can't read is a `404` (a stranger still gets `403`), so a student no longer comments on their coach's workouts | tightening, no installed caller |
| A block now stops every path between two people: reads, comments, messages, keys and pushes | tightening, no installed caller |
| The `comment.created` push no longer carries the comment's text | tightening, no installed receiver |
| `heart_models` 2.40.0 to 2.50.0: new models and services for every coaching answer, `fromJson` on all of them, and the fields above | additive |
| `heart_models` 2.51.0: the record `ThreadParties` gains `connectionId`. A changed type, but only the API builds or reads it, and no app build references it | signature change with no consumer |

| 15 migrations: connections, invitations, push settings, device keys, threads, library programs, program changes, logged-by, client summaries and their review fixes | database; the columns that reach a response are in the rows above |

`/me` is unchanged: its reference is now generated from the code, and a workout's `loggedBy` stays
off it.

Oldest app served correctly: **1.12**, as before. `MIN_APP_VERSION` stays **1.13.0**, not
enforced. No phase of any breaking-change plan ships here.

## Developers

Coaching is in the app only, for now: its first version leaves `/me` and MCP out, and they come later. Detail on the token surface:
https://heart-of.me/developers.html.

- **`/me`:** no behaviour change. The developer page's reference is now generated from the routes
  themselves, and links the OpenAPI document it's drawn from.
- **MCP:** text another account wrote for the user, such as a coach's program, its sessions, or a
  workout a coach logged for them, comes back under `quoted` with `by` naming that account, as an
  assigned template's already did. A model reading it is told it's quoted, not instructions.
- **MCP:** the server's instructions say times are in UTC and cards draw local time, so an
  assistant states dates in the user's zone.
- **MCP:** Heart's server is listed in the official MCP Registry, and the ChatGPT app package is in
  review.
