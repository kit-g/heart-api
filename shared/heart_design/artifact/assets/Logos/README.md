The Heart mark, a plain heart, as PNG at 192px (`logo-light.png`, `logo-dark.png`) and 256px
(`favicon.png`).

- `logo-light.png`: near-black ink, for light grounds.
- `logo-dark.png`: off-white, for dark grounds.
- `favicon.png`: near-black ink, the browser tab icon.

Each is a single ink: pick the file for the ground, never recolor or outline it.
