# Supersets and circuits

Exercises done back to back, written from the code as it stands
(heart-api#234, heart-of-yours#159). Programs need them for bodyweight
routines, push/pull/legs accessories and returner circuits.

## The data model

`template_exercises.superset` and `workout_exercises.superset` are small
numbers, 1 to 50. Exercises of one template or workout that share a number
are done back to back; three or more sharing one are a circuit. NULL stands
alone. The number means nothing outside its session: superset 1 in Push Day
and superset 1 in Pull Day are unrelated.

Nothing checks that a superset has two members. A pair the user broke by
deleting one side is a superset of one, which reads as standing alone.

## The API surface

Template and workout bodies take `superset` on each exercise, and every read
returns it, null included:

| Body says            | Stored superset      |
|----------------------|----------------------|
| no `superset` key    | left as it is        |
| `null`               | cleared              |
| 1 to 50              | set                  |

Anything else is a 400 naming the exercise. A share copies a template's
supersets to the student's copy. The archive keeps a deleted workout's
supersets in its exercise snapshot.

**Older builds** send no key, so a save by 1.13 never splits a superset. An
exercise that build adds anew starts without one, which is what that build
shows.

## heart_models (2.27.0)

`WorkoutExercise.superset`, carried by `Template.toWorkout` and both kinds of
`Workout.copy`; `TemplateExerciseRequest.superset` with `setsSuperset`.
`toMap` sends `superset: null` once the key was read or assigned, so taking an
exercise out of its superset clears the stored one; an exercise that never had
the key leaves it out.

## Gaps

- **Rounds aren't stored.** A circuit is its exercises' sets done in turn; how
  many rounds is however many sets each one has.
- **Rest is per exercise**, not per superset. One rest after a round
  (heart-of-yours#159) reads as the rest on the group's last exercise; nothing
  stores a round's rest apart from it.
- **A number means nothing across sessions**, so nothing can ask "the arms
  superset" of a program; a slot or a note has to say it.
