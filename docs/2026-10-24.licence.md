# Licences (heart-of-yours#482)

The server is AGPL-3.0 because the one thing worth guarding is a closed hosted copy of the API,
and AGPL is the licence that covers running code as a service; the server never ships through a
store, so the App Store's conflict with GPL terms doesn't reach it, and with contributions taken
inbound = outbound there is no relicensing to plan for, so no CLA. The shared packages
(`heart_models`, `heart_aws`, `heart_design`) are Apache-2.0: `heart_models` and `heart_design`
are compiled into the app, so a copyleft licence there would choose the app's licence for it, and
`heart_aws` is the part meant to be reused; Apache over MIT or BSD for its patent grant and its
explicit trademark clause. `content/` is CC BY 4.0, since it is data and prose the CDN already
serves publicly, and reuse with credit is what "your data is yours" implies for the library too.
The site's copy and the blog stay all rights reserved, and the name and logo are trademarks no
licence grants. Research on other apps' exports stays out of the repository entirely (the dev
bucket), and the exercise media were never in it. `NOTICE` maps each directory to its licence and
lists what isn't ours.
