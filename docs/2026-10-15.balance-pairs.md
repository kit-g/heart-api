# Balance pairs

The server's side of the app's balance view (heart-api#270; the app side is
heart-of-yours#342): opposing movement patterns set against each other over
the user's recent weeks. Push goes against pull, hinge against squat, curls
against triceps extensions, and leg extensions against leg curls.

## Content, not app logic

The pairs are a training-science judgement, so they live in content and change
without an app release:
- `content/balance_pairs.yml` is the source.
- `scripts/balance_content.py` checks and renders it.
- `scripts/publish_content.sh` publishes it as `static/balance` with the
  other content objects: dev on merge, prod by hand from a release tag.

```jsonc
{
  "version": 1,
  "pairs": [
    {
      "key": "push_pull",
      "left": {
        "key": "push",
        "name": {"en": "Push", "es": "Empuje", "fr": "Poussée", "ru": "Жимы"},
        "patterns": ["horizontal_press", "incline_press", "decline_press", "vertical_press", "chest_dip"]
      },
      "right": {
        "key": "pull",
        "name": {"en": "Pull", "es": "Tracción", "fr": "Tirage", "ru": "Тяги"},
        "patterns": ["horizontal_row", "vertical_pull"]
      }
    }
    // hinge_squat, elbow, knee
  ]
}
```

- **A side counts the sets of its patterns**, the library's movement pattern
  keys: the same vocabulary as `movement.groups` on an exercise, and as a
  custom exercise's pattern (heart-api#269).
- **Counts only.** A side has its key, its name in every library language and
  its patterns, nothing else. There's no verdict, threshold or advice; the
  checker refuses any other field.
- **The checker refuses:**
  - a pattern the library doesn't have;
  - a pattern on both sides of a pair, which would weigh nothing either way;
  - a side missing a language;
  - a duplicate key.
- The four pairs are the ones the app shipped with (`balanceContent`), so
  serving them changes nothing a user sees.

## Gaps

- **Not on prod yet.** It goes out with `static/programs` and `static/go-easy`
  once the copy is reviewed. The `es`, `fr` and `ru` names are
  machine-translated.
- **No pair for the hips or shoulders yet.** Abduction against adduction, and
  front raises against rear-delt work, have few library exercises behind them.
  They can join as content when the library has more.
